============================================================
  gm6 — 단어장 & 리더 (사용법)
============================================================

■ 실행 / 종료
  - 실행 : PowerShell에서  cd D:\lab\gm6  후  npm start
  - 종료 : 시스템 트레이(우하단)의 아이콘 우클릭 → 종료
  - 처음 켜면 창은 숨김 상태이고, 트레이에 아이콘만 생긴다.
    (작업표시줄에는 표시되지 않음)

------------------------------------------------------------
■ 전역 단축키 (어느 프로그램에서든 작동)
------------------------------------------------------------
  Alt + Q          켜기 / 숨기기 (보스키, 토글)
  Ctrl + Alt + H   무조건 즉시 숨기기 (패닉)
  Alt + 1          리더(Reading) 화면으로 전환  ← 기본 화면
  Alt + 2          단어장(単語) 화면으로 전환
  Alt + 3          N3 문장 화면으로 전환

  ※ 켜져 있는 동안 창은 항상 화면 최상단에 고정된다.
  ※ Esc / Alt+Q 로 숨겨도 마지막 위치는 그대로 기억한다.
    (모서리 자동 배치는 앱을 처음 켤 때 1회만)

------------------------------------------------------------
■ 창 안에서의 조작
------------------------------------------------------------
  상단 바 드래그   창 위치 이동
  ✕ 버튼           숨기기
  Esc              숨기기

[ 단어장 화면 ]
  목록 / 플래시카드  상단 버튼으로 모드 전환
  뜻 가리기          뜻을 흐리게 가림 (카드 클릭 시 해당 뜻만 보임)

  · 플래시카드
      ← / →        이전 / 다음 카드
      ↑  또는 클릭  카드 뒤집기 (앞:한자  ↔  뒤:히라가나·뜻)
      🔀 섞기        카드 순서 무작위 섞기

[ 리더 화면 ]
  A- / A+          글자 크기 작게 / 크게
  스크롤           본문 위아래 이동

------------------------------------------------------------
■ 설정 바꾸기 (main.js 맨 위 설정 블록)
------------------------------------------------------------
  WIN_W / WIN_H    창 너비 / 높이 (px)
  MARGIN           화면 모서리에서 띄울 간격 (px)
  CORNER           최초 배치 위치
                   ('bottom-right' / 'bottom-left' /
                    'top-right' / 'top-left')
  KEY_TOGGLE       보스키 (기본 Alt+Q)
  KEY_PANIC        패닉키 (기본 Ctrl+Alt+H)
  KEY_READER       리더 전환키 (기본 Alt+1, 기본 화면)
  KEY_VOCAB        단어장 전환키 (기본 Alt+2)
  KEY_SENT         N3 문장 전환키 (기본 Alt+3)

  · 단어 추가/수정 : game.js 의 WORDS 배열
        {row:"か", kana:"...", kanji:"...", mean:"..."}
  · 리더 내용 변경 : reader.js 의 sections 배열
        { h:"소제목", p:["문단", "문단", ...] }

------------------------------------------------------------
■ 파일 구성
------------------------------------------------------------
  main.js       창 / 단축키 / 트레이 (Electron 메인)
  preload.js    화면과 메인 사이 연결
  index.html    화면 구조
  style.css     디자인
  game.js       단어장 (목록 + 플래시카드) + 화면 전환
  reader.js     리더 콘텐츠
  icon.png      트레이 아이콘
